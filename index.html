Estruturas Condicionais

As estruturas condicionais em JavaScript permitem que o código tome decisões com base em condições.

Estrutura IF/ELSE

A estrutura if else é um comando de decisão na programação que executa um bloco de código se uma condição for verdadeira (if), e outro bloco alternativo se ela for falsa (else). Os componentes principais são o IF, o ELSE IF e o ELSE

Estrutura SWITCH CASE

A estrutura switch case em JavaScript serve para testar o valor de uma variável contra várias opções. Ela usa switch, case, break e default




Estruturas de Repetição

As estruturas de repetição em JavaScript permitem que um bloco de código seja executado várias vezes com base em uma condição.

Estrutura FOR

A estrutura for é um loop que permite executar um bloco de código repetidamente, com base em uma condição de controle. Ela é composta por três partes: inicialização, condição e incremento/decremento.

Estrutura DO WHILE

A estrutura do while é um loop que executa um bloco de código pelo menos uma vez, e depois continua a execução enquanto uma condição for verdadeira. A diferença em relação ao while é que o do while garante que o código seja executado pelo menos uma vez, mesmo que a condição seja falsa.

Estrutura WHILE DO

A estrutura while do é um loop que executa um bloco de código enquanto uma condição for verdadeira. A diferença em relação ao do while é que o while do verifica a condição antes de executar o código, podendo não executar o bloco nenhuma vez se a condição for falsa.




Estrutura de Dados

As estruturas de dados em JavaScript são formas de organizar e armazenar dados de maneira eficiente, permitindo que sejam manipulados e acessados de forma rápida e fácil.

Estrutura Array Unidimensional

A estrutura array é uma coleção de elementos, que podem ser de qualquer tipo de dado, como números, strings, objetos, etc. Os elementos são armazenados em índices numéricos, começando do zero. Arrays são úteis para armazenar listas de itens e realizar operações como iteração, filtragem e ordenação.

Estrutura Array Bidimensional

Um array bidimensional (ou matriz) é uma estrutura de dados que organiza valores em linhas e colunas, funcionando como uma tabela. Na prática, ele opera como um array de arrays, onde cada posição guarda outra lista de elementos. Para encontrar um valor exato, usamos dois índices: o primeiro indica a linha e o segundo indica a coluna
